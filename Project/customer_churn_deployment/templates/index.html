About ChurnAI

Customer Churn Prediction Using Elastic Net Regularized Logistic Regression.

Project Overview

This project uses machine learning to estimate whether a telecom customer may discontinue a service.

Algorithm

Logistic Regression with Elastic Net regularization.

Preprocessing

StandardScaler for numerical features and OneHotEncoder for categorical features.

Application

Flask web application with a customer form and prediction display.

Why Predict Churn?

Businesses can use churn predictions to identify customers who may need additional support, review their service experience, and consider suitable retention strategies.

Contact

Project information and support.

Customer Churn Prediction Project

This academic application demonstrates a machine learning pipeline and a web-based prediction interface.

Technical Stack

Python, Flask, Pandas, NumPy, Scikit-learn, HTML, CSS and JavaScript.
